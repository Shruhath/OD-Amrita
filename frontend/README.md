# OD-Manager
### A platform for the coordinators, teachers and the admins to manage the ODs.

# Steps to run
````
git clone https://github.com/jimitnick/OD-Amrita.git

cd frontend

npm i
````

## To run and see the output in the Expo Go app
### iOS
```
npx expo start --ios
```
### Android
```
npx expo start --android
```
### Web
```
npx expo start --web
```

# To use the native packages once installed use the development build
## To run the development build 

## Make sure to have the following installed before you run the commands below
```
1. If using Android, make sure to have the **Android studio installed** as adb is requried for the native packages to run properly
2. If using iOS, make sure to have the **XCode installed** as it is requried for the native packages to run properly
```

### The build commands are given below
### iOS
```
npx expo run:ios
```
### Android
```
npx expo run:android
```
### Web
```
npx expo run:web
```
